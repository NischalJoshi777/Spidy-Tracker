Spidy Tracker

A sample Spider-Man themed app for tracking and reporting city sightings on an interactive map. Inspired from spider man brand new day.

The app includes:

- A city map screen built using  OpenStreetMap tiles
- Custom embedded Spider-Man marker icons for each sighting
- Tap-to-add reporting directly from the map
- A feed screen that lists reported sightings with filter chips
- A details dialog for marker taps that matches the feed card style
